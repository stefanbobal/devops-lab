# DevOps Stack Test

Hands-on learning environment for modern DevOps and platform engineering.

## Goal

Build, deploy, automate, monitor and troubleshoot containerized applications using a modern GitOps / DevOps toolchain.

## Technologies

- Linux
- Docker / containerd
- Kubernetes
- Terraform
- GitHub Actions
- ArgoCD
- Prometheus / Grafana
- GCP / GKE

## Labs

1. [K3s Basics](labs/01-k3s-basics.md)
2. Kubernetes Services
3. ConfigMaps & Secrets
4. Ingress
5. GitHub Actions
6. ArgoCD / GitOps
7. Prometheus & Grafana
8. Terraform
9. GCP / GKE

## Environment

- Host: Windows
- Hypervisor: VirtualBox
- Guest OS: Ubuntu Server
- Kubernetes distribution: k3s
- Development environment: VS Code Remote SSH

## Learning approach

The goal of this repository is not only to deploy working solutions, but also to understand how each component works, how to troubleshoot failures, and how the individual DevOps tools fit together.
